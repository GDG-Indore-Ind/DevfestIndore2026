# Retired source material

`legacy-planning-data.json` preserves unreviewed examples from older code: proposed current speakers, example agendas, sponsor tiers, statistics and venue concepts. It is an archive, not a publishing input. None of these examples is promoted to confirmed website content.

The three original Sessionize/workshop `.xlsx` files are retained in `spreadsheets/` for reference. They are not read during development or builds. Future updates belong in `/content`, with public profiles and organization records maintained once and referenced by stable IDs.

Migration on 21 October 2026 preserved the current public site’s 29 archived session records, 14 team members, 18 workshops, 25 historical sponsor listings, two confirmed featured collaborators, three ecosystem organizations, six passes, two verified photographs and six historical event records. Cross-record references use 43 unique people/group records and 35 organizations. Existing optional missing ambassador placeholder photos were removed; no referral code was changed.

See [the editing guide](../../content/README.md).
