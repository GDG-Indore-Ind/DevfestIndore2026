# Profile review

Run `npm run content:review` and open `generated/README.md` to review the current people and organization records. The generated packets are local, ignored by Git and not used by the website. Regenerate them after content changes; the index lists the current records.

Start with Karan Mittal, as requested by the organizer. Keep independent verification in `evidence/`; the exporter links to it and does not overwrite it. The team responsibilities note is also maintained separately.

Approvals require explicit organizer confirmation. For an approved profile, apply the agreed corrections and record the exact revision, date and confirmation reference in `content/approvals.json`. Existing baseline fingerprints are not approvals, and generating a packet does not approve a profile or enable the new directory. See the [content guide](../../content/README.md) for the review and migration rules.
